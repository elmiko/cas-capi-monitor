# cas-capi-monitor visualizer

this python app will process the output of cas-capi-monitor to create a
chart for visualizing the output.

## quickstart

1. create a venv, `python -m venv env`
2. activate venv, `source env/bin/activate`
3. install dependencies, `pip install -r requirements.txt`
4. run visualizer, `python main.py /path/to/cas-capi-monitor/logs.txt`

if this worked you will be looking at a chart in your webbrowser.
